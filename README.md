# Heart Love Languages

Shareable browser version plus the original Python/Pygame animation. The web app opens as a full-screen heart made from "I love you" translations, and the center text cycles through the same language list.

## Web Version

```powershell
npm install
npm run dev
```

Edit `phrases` near the top of `app/LoveHeart.tsx` to add your own languages or change the messages.

## Python Version

```powershell
python -m pip install -r requirements.txt
python heart_love_languages.py
```

Edit `PHRASES` near the top of `heart_love_languages.py` to change the Python version.
